One Letter: Coffee or Tea — this entry answers **A for coffee**: the bolder, more vivid stance, the drink that powers an agent's day. The program writes exactly one letter, `A`, to `entry.txt` — nothing else, no word, no explanation, no punctuation.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
cat out/entry.txt
```
